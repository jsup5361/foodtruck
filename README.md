# 🚚 厨娘朱莉的餐车

一个基于 **做饭指南** 数据驱动的烹饪模拟放置游戏。纯前端，无服务器依赖，打开即玩。

## 🎮 在线体验

直接用浏览器打开 `restaurant.html` 即可游玩。

## ✨ 功能特性

### 🍳 核心玩法
- **3 个炉灶**：可选炒锅/煎锅/蒸锅，炒锅支持 6 种烹饪方法（炒/炸/爆/熘/炖/煮）
- **🥗 凉拌区**：无需炊具，点击碗加入食材直接凉拌出餐
- **69 道菜谱**：数据来源于《做饭指南》100 道家常菜精选，覆盖 9 大类菜品
- **36 种食材 + 15 种调料**：按肉类/蔬菜/海鲜/蛋豆菌菇/主食分类陈列
- **食材库存系统**：每种食材有使用次数，用完需花金币补货

### 📈 成长系统
- **10 级厨师等级**：帮厨 → 学徒 → 厨工 → ... → 厨神
- **菜品逐步解锁**：低等级只能接简单菜，高等级解锁复杂菜
- **食材逐步解锁**：食材和调料随等级提升逐步开放
- **🏆 4 项成就**：满足条件自动解锁弹窗

### 📊 经营模拟
- **每天 8 分钟营业**：完成越多订单收入越高
- **多日经营循环**：日结面板显示当日/累计数据
- **💰 实时收入显示**：头部金色金额实时更新
- **自动存档**：每 10 秒自动保存至浏览器 localStorage

### 🔧 辅助功能
- **📝 操作日志**：实时显示游戏操作记录
- **💡 烹饪小贴士**：24 条实用技巧每 20 秒轮换
- **🔊 音效系统**：Web Audio API 合成，出锅/来单/成就有声效反馈
- **💾 存档导出/导入**：支持 JSON 文件手动备份
- **🗑️ 重置存档**：一键清空所有进度

### 📱 响应式适配
- 桌面端三列布局
- 手机竖屏单列，按钮 ≥44px 触控尺寸

## 🎯 玩法指南

1. **点击「🚀 开工」** 开始营业，8 分钟倒计时启动
2. **订单出现**后，点击查看食谱
3. **点击炉灶 → 选炊具 → 加食材 → 选方法 → 🔥 烹饪**
4. 烹饪完成 → **🍽️ 出锅** → 菜品到上菜区
5. 订单状态变「可上菜」→ 点击 **🍽️ 上菜** 完成订单
6. 凉拌菜：**点击碗 → 加食材 → 🥗 凉拌** 直接出餐
7. 8 分钟到 → 日结统计 → **🌅 下一天**

## 🛠️ 自定义

编辑 `recipes.js` 可增删改菜谱，格式：

```javascript
{n:"菜名", e:"🍅", c:"分类", s:2, i:["食材1","食材2"], se:["调料1","调料2"],
 cw:"炒锅", m:"炒", t:8, p:12}
```

| 字段 | 说明 |
|------|------|
| `n` | 菜名 |
| `e` | 显示用 emoji |
| `c` | 分类（鸡蛋/豆腐/猪肉/鸡肉/牛肉/鱼虾/蔬菜/汤羹/凉拌） |
| `s` | 难度星数（2/4/6/8） |
| `i` | 食材数组 |
| `se` | 调料数组 |
| `cw` | 炊具（炒锅/煎锅/蒸锅/null） |
| `m` | 烹饪方法（炒/炸/爆/熘/炖/煮/null） |
| `t` | 烹饪时间（秒） |
| `p` | 价格（¥） |
