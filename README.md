# 🚚 厨娘朱莉的餐车 + 🌾 农场联动

一个融合 **烹饪模拟** 与 **农场种植** 的放置经营游戏。纯前端，无服务器依赖，打开即玩。

## 🎮 在线体验

直接访问 [https://jsup5361.github.io/foodtruck/](https://jsup5361.github.io/foodtruck/) 即可游玩。

## ✨ 功能特性

### 🍳 餐车系统
- **1 个炉灶**：可选炒锅/煎锅/蒸锅，炒锅支持 6 种烹饪方法（炒/炸/爆/熘/炖/煮）
- **🔪 菜板 / 🔥 烤箱**（暂未开放）：占位预留
- **🥗 凉拌区**：无需炊具，点击碗加入食材直接凉拌出餐
- **70 道菜谱**：数据来源于《做饭指南》，覆盖 9 大类菜品
- **食材使用次数系统**：每种食材有使用次数（调料 ¥2/30 次廉价大包装，普通食材按稀有度定价）
- **开工前可补货**：非营业时间点击食材即为购买

### 🌾 农场系统
- **5×5 农田网格**，逐步开垦扩张
- **13 种作物**（4 级 Tier：4h / 8h / 12h / 24h 成熟）
- **🎒 种子袋**：点击选种 → 点击空地种植 / **🌱 一键种植**（优先种高级作物）
- **📦 农仓库存**：收获食材自动入库，餐车优先消耗农产（每单位 ×3~6 次使用）
- **💰 农产出售**：按种子价 × (1 + tier×0.25) 定价，支持单个出售或 **💰 全部卖出**
- **🌾 一键收获**：批量收获所有成熟作物
- **离线收益**：离线期间作物继续生长，加载时自动计算
- **⏩ 调试模式**：快进 1h/4h/8h/24h 或全部成熟

### 📈 成长系统
- **10 级厨师等级**：帮厨 → 学徒 → 厨工 → ... → 厨神
- **菜品逐步解锁**：低等级只能接简单菜，高等级解锁复杂菜
- **食材逐步解锁**：食材和调料随等级提升逐步开放
- **🏆 4 项成就**：满足条件自动解锁弹窗

### 📊 经营模拟
- **每日上限 15 道菜**，完成后自动打烊
- **北京时间 12pm 后** 才能再次开店
- **菜品定价** = 食材成本 × 星级倍率（s:2→3倍，s:4→5倍，s:6→7倍，s:8→10倍）
- **多日经营循环**：日结面板显示当日/累计数据
- **💰 统一金币**：餐车收入、农场出售、购买种子/补货全通用
- **自动存档**：每 10 秒自动保存至浏览器 localStorage

### 🔧 辅助功能
- **📝 操作日志**：实时显示游戏操作记录
- **💡 烹饪小贴士**：24 条实用技巧每 20 秒轮换
- **🔊 音效系统**：Web Audio API 合成，出锅/来单/成就有声效反馈
- **💾 存档导出/导入**：支持 JSON 文件手动备份（包含全部游戏数据）
- **🗑️ 重置存档**：一键清空所有进度

### 📱 响应式适配
- 桌面端三列布局
- 手机竖屏单列，按钮 ≥44px 触控尺寸

## 🎯 玩法指南

### 🚚 餐车部分
1. **北京时间 12pm 后** 点击「🚚 开店」开始营业
2. **订单出现**后，点击查看食谱
3. **点击炉灶 → 选炊具 → 加食材 → 选方法 → 🔥 烹饪**
4. 烹饪完成 → **🍽️ 出锅** → 菜品到上菜区
5. 订单状态变「可上菜」→ 点击 **🍽️ 上菜** 完成订单
6. 凉拌菜：**点击碗 → 加食材 → 🥗 凉拌** 直接出餐
7. 完成 **15 道菜** 或点击「⏰ 打烊」结束营业

### 🌾 农场部分
1. 切换到农场 Tab
2. **🏪 种子商店**：购买种子（弹窗输入数量，默认空地数）
3. **🎒 种子袋**：点击选种 → 点击空地种植（或 **🌱 一键种植**）
4. 等待作物成熟（4h / 8h / 12h / 24h）
5. **🌾 一键收获** 或逐个点击成熟作物收获
6. 农产进入农仓，餐车自动优先消耗
7. 多余农产可 **💰 出售**

## 🛠️ 自定义

编辑 `recipes.js` 可增删改菜谱，格式：

```javascript
{n:"菜名", e:"🍅", c:"分类", s:2, i:["食材1","食材2"], se:["调料1","调料2"],
 cw:"炒锅", m:"炒", t:8, p:12}
```

| 字段 | 说明 |
|------|------|
| `n` | 菜名 |
| `e` | 显示用 emoji |
| `c` | 分类（鸡蛋/豆腐/猪肉/鸡肉/牛肉/鱼虾/蔬菜/汤羹/凉拌） |
| `s` | 难度星数（2/4/6/8） |
| `i` | 食材数组 |
| `se` | 调料数组 |
| `cw` | 炊具（炒锅/煎锅/蒸锅/null） |
| `m` | 烹饪方法（炒/炸/爆/熘/炖/煮/null） |
| `t` | 烹饪时间（秒） |
| `p` | 价格（¥）= 食材成本 × 星级倍率 |
