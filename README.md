# 🚚 厨娘朱莉的餐车 + 🌾 农场联动

一个融合 **烹饪模拟** 与 **农场种植** 的放置经营游戏。纯前端，无服务器依赖，打开即玩。

## 🎮 在线体验

直接访问 [https://jsup5361.github.io/foodtruck/](https://jsup5361.github.io/foodtruck/) 即可游玩。

## ✨ 功能特性

### 🍳 餐车系统
- **1 个炉灶**：可选炒锅/煎锅/蒸锅，炒锅支持 6 种烹饪方法（炒/炸/爆/熘/炖/煮）
- **🔪 菜板系统**：需要切的食材（番茄/土豆/黄瓜等 17 种）先上菜板切块，切好后入锅/入碗
- **🥗 凉拌区**：无需炊具，选中碗加入食材直接凉拌出餐
- **93 道菜谱**：来源于 HowToCook 开源食谱库
- **食材使用次数系统**：每种食材有使用次数
- **开工前可补货**：非营业时间点击食材即为购买

### 🔪 切菜 & 收益系统
| 切菜状态 | 收益 | 条件 |
|---------|------|------|
| ⭐ 完美切块 | **×1.25** | 所有需切食材完成指定刀数 |
| — 正常 | ×1.0 | 无需要切的食材/切了部分 |
| ⚠️ 未切块 | **×0.75** | 有需切食材但一刀没切 |
| 🤮 黑暗料理 | **×0.25** | 食材完全不匹配任何菜谱 |

### 📅 日期事件系统
每 3-5 天随机触发一个场景事件，影响当日营业：

**正常事件：** 工地出摊（高热量菜畅销）、养老院（炖菜+烹饪时间+10%）、三伏天（凉菜暴增）、学校门口（低价菜为主）、美食节（切菜要求严格）

**无厘头事件：** 素食游行（全素日）、网红探店（收入×1.5但倒计时+40%）、猫咪大闹（食材消耗×2）、厨神附体（自动完美切，5%糊锅）、次元裂缝（随机乱点怪菜）

### 🌾 农场系统
- **5×5 农田网格**，逐步开垦扩张
- **13 种作物**（4 级 Tier：5m/10m/20m/40m 成熟）
- **三阶段生长动画**：种子 → 嫩芽 → 成熟食材图
- **🎒 种子袋**：点击选种 → 点击空地种植 / 🌱 一键种植
- **📦 农仓库存**：收获食材自动入库，餐车优先消耗
- **🌾 一键收获**：批量收获所有成熟作物
- **离线收益**：离线期间作物继续生长

### 📈 成长系统
- **10 级厨师等级**：帮厨 → 学徒 → 厨工 → ... → 厨神
- **菜品逐步解锁**：低等级只能接简单菜，高等级解锁复杂菜
- **🏆 4 项成就**：第一桶金 / 菜真的熟了 / 牛刀小试 / 叫我厨神

### 🗣️ 客户反馈
上菜/超时后弹出评价（各十余条随机轮播）

### 🖼️ 食材图片
55 张食材漫画风格图片替代纯 emoji 显示，农场作物三阶段生长图片

## 🎯 玩法指南

### 🚚 餐车部分
1. 点击「🚚 开店」开始营业（每整点可开一次）
2. **订单出现**后，点击查看食谱（含切块需求 🔪）
3. **切菜**：选中菜板 → 点击食材 → 🔪 切块 → 🍳 入锅/入碗
4. **点击炉灶 → 选炊具 → 加食材 → 选方法 → 🔥 烹饪**
5. 烹饪完成 → **🍽️ 出锅** → 菜品到上菜区
6. 订单状态变「可上菜」→ 点击 **🍽️ 上菜** 完成
7. 凉拌菜：**选中碗 → 加食材 → 🥗 凉拌** 直接出餐
8. 完成 **15 道菜** 或点击「⏰ 打烊」结束营业

### 🌾 农场部分
1. 切换到农场 Tab
2. **🏪 种子商店**：购买种子
3. **🎒 种子袋**：点击选种 → 点击空地种植
4. 等待作物成熟（5m/10m/20m/40m）
5. **🌾 一键收获** 或逐个点击成熟作物收获
6. 农产进入农仓，餐车自动优先消耗
