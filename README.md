# 🚚 厨娘朱莉的餐车 + 🌾 农场联动

一个融合 **烹饪模拟** 与 **农场种植** 的放置经营游戏。纯前端，无服务器依赖，打开即玩。

## 🎮 在线体验

直接访问 [https://jsup5361.github.io/foodtruck/](https://jsup5361.github.io/foodtruck/) 即可游玩。

## ✨ 功能特性

### 🍳 餐车系统
- **1 个炉灶**：可选炒锅/煎锅/蒸锅，炒锅支持 6 种烹饪方法（炒/炸/爆/熘/炖/煮）
- **🔪 菜板系统**：需要切的食材（番茄/土豆/黄瓜等 17 种）先上菜板切块，切好后入锅/入碗
- **🥗 凉拌区**：无需炊具，选中碗加入食材直接凉拌出餐（也支持菜板切块后入碗）
- **🔥 烤箱**（暂未开放）
- **70 道菜谱**：数据来源于《做饭指南》，覆盖 9 大类菜品
- **食材使用次数系统**：每种食材有使用次数（调料 ¥2/30 次廉价大包装，普通食材按稀有度定价）
- **开工前可补货**：非营业时间点击食材即为购买

### 🔪 切菜 & 收益系统
| 切菜状态 | 收益 | 条件 |
|---------|------|------|
| ⭐ 完美切块 | **×1.25** | 所有需切食材完成指定刀数 |
| — 正常 | ×1.0 | 无需要切的食材/切了部分/刀数不够 |
| ⚠️ 未切块 | **×0.75** | 有需切食材但一刀没切 |
| 🤮 黑暗料理 | **×0.25** | 食材完全不匹配任何菜谱 |

### 🌾 农场系统
- **5×5 农田网格**，逐步开垦扩张（¥15~¥265/块）
- **13 种作物**（4 级 Tier：**5m / 10m / 20m / 40m** 成熟）
- **🎒 种子袋**：点击选种 → 点击空地种植 / **🌱 一键种植**（优先种高级作物）
- **📦 农仓库存**：收获食材自动入库，餐车优先消耗农产（每单位 ×3~6 次使用）
- **💰 农产出售**：按种子价 × (1 + tier×0.25) 定价，支持单个出售或 **💰 全部卖出**
- **🌾 一键收获**：批量收获所有成熟作物
- **离线收益**：离线期间作物继续生长，加载时自动计算

### 📈 成长系统
- **10 级厨师等级**：帮厨 → 学徒 → 厨工 → ... → 厨神
- **等级阈值**：[0, 5, 12, 22, 35, 50, 68, 88, 110, 135] 累计完成菜品数
- **菜品逐步解锁**：低等级只能接简单菜，高等级解锁复杂菜
- **食材逐步解锁**：食材和调料随等级提升逐步开放
- **🏆 4 项成就**：第一桶金（首次上菜）/ 菜真的熟了 / 牛刀小试 / 叫我厨神

### 📊 经营模拟
- **整点小时制**：每整点可开店一次，相邻小时可连开（10点结束→11点即开）
- **每日上限 15 道菜**，完成后自动打烊（营业时长约 8 分钟）
- **菜品定价** = 食材成本 × 星级倍率（s:2→3倍，s:4→5倍，s:6→7倍，s:8→10倍）
- **初始资金 ¥50**
- **💰 统一金币**：餐车收入、农场出售、购买种子/补货全通用
- **自动存档**：每 10 秒自动保存至浏览器 localStorage

### 🔧 辅助功能
- **📝 操作日志**：实时显示游戏操作记录（最多 5 条）
- **💡 烹饪小贴士**：25 条实用技巧每 20 秒轮换
- **🔊 音效系统**：Web Audio API 合成，出锅/来单/成就有声效反馈
- **💾 存档导出/导入**：支持 JSON 文件手动备份
- **🗑️ 重置存档**：一键恢复初始状态（¥50 + 白萝卜×5）
- **⏩ 调试模式**（仅本地）：快进农田时间

## 🎯 玩法指南

### 🚚 餐车部分
1. 点击「🚚 开店」开始营业（每整点可开一次）
2. **订单出现**后，点击查看食谱（含切块需求 🔪）
3. **切菜**：选中菜板 → 点击食材 → 🔪 切块 → 🍳 入锅/入碗
4. **点击炉灶 → 选炊具 → 加食材 → 选方法 → 🔥 烹饪**
5. 烹饪完成 → **🍽️ 出锅** → 菜品到上菜区
6. 订单状态变「可上菜」→ 点击 **🍽️ 上菜** 完成
7. 凉拌菜：**选中碗 → 加食材 → 🥗 凉拌** 直接出餐
8. 完成 **15 道菜** 或点击「⏰ 打烊」结束营业

### 🌾 农场部分
1. 切换到农场 Tab
2. **🏪 种子商店**：购买种子
3. **🎒 种子袋**：点击选种 → 点击空地种植
4. 等待作物成熟（5m / 10m / 20m / 40m）
5. **🌾 一键收获** 或逐个点击成熟作物收获
6. 农产进入农仓，餐车自动优先消耗

## 🛠️ 菜谱格式

编辑 `recipes.js` 可增删改菜谱，格式：

```javascript
{n:"菜名", e:"🍅", c:"分类", s:2, i:["食材1","食材2"], se:["调料1","调料2"],
 cw:"炒锅", m:"炒", t:8, p:12}
```

| 字段 | 说明 |
|------|------|
| `n` | 菜名 |
| `e` | emoji |
| `c` | 分类（鸡蛋/豆腐/猪肉/鸡肉/牛肉/鱼虾/蔬菜/汤羹/凉拌）|
| `s` | 难度星数（2/4/6/8）|
| `i` | 食材数组 |
| `se` | 调料数组 |
| `cw` | 炊具（炒锅/煎锅/蒸锅/null=凉拌）|
| `m` | 烹饪方法（炒/炸/爆/熘/炖/煮/null）|
| `t` | 烹饪时间（秒）|
| `p` | 价格（¥）|
